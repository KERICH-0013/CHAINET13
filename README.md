# chainet

 CHAINET is a Tea Farming Assistant mobile application developed as my final year project at the Technical University of Kenya. The app empowers smallholder tea farmers with data-driven insights to:

- Increase tea yields through personalized crop recommendations
- pest detection module
- Access real-time weather forecasts** for informed farming decisions
- Provision of market updates
- Detect crop diseases
- Provision of Ai (chatbot)
- integrated dashboard
-  Detailed farming guide
